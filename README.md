# Vibe Finder

Современный одностраничный сайт для выявления настроения и подбора персонального вайб-пространства.

## Что входит в проект

- стартовый экран с атмосферной анимацией и тёмной палитрой;
- интерактивный опрос из 5 вопросов;
- логика определения одного из четырёх вайбов: "Спокойный космос", "Солнечный заряд", "Ночной неон" и "Лесной отдых";
- персональная подборка цитат;
- фоновая музыка по выбранному вайбу;
- большие интерактивные мини-игры для каждого вайба;
- адаптивный интерфейс для компьютера и мобильных устройств.

## Структура проекта

- `index.html` — разметка стартового экрана, опроса и финального вайб-экрана;
- `style.css` — стили, темы, анимации, адаптивность и мобильные исправления;
- `script.js` — логика опроса, музыкального плеера, вайбов и мини-игр;
- `audio/` — папка с MP3-файлами для треков каждого вайба.

## Как запустить локально

1. Откройте папку проекта в терминале.
2. Запустите сервер:

```bash
python -m http.server 8000
```

3. Откройте в браузере:

```text
http://localhost:8000
```

> Сайт работает без сторонних библиотек, API-ключей и платных сервисов.

## Как опубликовать через GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы проекта.
2. Убедитесь, что в корне репозитория находятся:
   - `index.html`
   - `style.css`
   - `script.js`
   - папка `audio/` с MP3-файлами
3. В GitHub откройте репозиторий → Settings → Pages.
4. В разделе "Build and deployment" выберите:
   - Source: Deploy from a branch
   - Branch: `main` или `master`
   - Folder: `/root`
5. Сохраните настройки.
6. GitHub Pages выдаст публичную ссылку вида:

```text
https://<username>.github.io/<repository-name>/
```

> Для GitHub Pages важно использовать только относительные пути, например `audio/cosmos.mp3`, а не локальные дисковые пути. Все файлы должны лежать в корне проекта и в папке `audio/`.

## Важно для публикации

- Папка `audio/` должна быть в репозитории и содержать все три MP3-файла.
- Используются относительные пути, поэтому сайт корректно открывается на GitHub Pages.
- Никакие локальные пути компьютера, платные сервисы или зависимости не требуются.
