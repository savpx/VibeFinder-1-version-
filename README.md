# Vibe Finder

Интерактивный сайт, который помогает определить текущее настроение и подобрать подходящее вайб-пространство.

## Как это работает

1. Нажми «Начать».
2. Ответь на несколько коротких вопросов о настроении и самочувствии.
3. Получи подходящий вайб с атмосферным оформлением, музыкой, цитатой и интерактивной игрой.

## Вайбы

- **Спокойный космос** — тишина, звёзды и медитативное создание созвездий.
- **Солнечный заряд** — свет, энергия и сбор солнечного потока.
- **Ночной неон** — неоновая атмосфера и спокойный ритм.
- **Лесной отдых** — природные цвета, уют и отдых от суеты.

## Возможности

- индивидуальное оформление для каждого вайба;
- фоновая музыка с компактным плеером;
- атмосферные цитаты;
- интерактивные игры;
- удобная версия для компьютеров и телефонов.

## О проекте

Vibe Finder создан как учебный проект. Его цель — подарить пользователю короткий приятный цифровой отдых и помочь переключиться на подходящее настроение.
